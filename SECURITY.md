## Reporting a Vulnerability

If you discover a security vulnerability in **Billiards with Cheats**, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Use GitHub's [private vulnerability reporting](https://github.com/Convux611/billiards-with-cheats/security/advisories/new).
3. Describe the issue, steps to reproduce, and expected vs actual behavior.

You can expect a response within **7 days**. Thank you for helping keep this project safe! 🎱
